# Security policy

Please do not report a vulnerability in a public issue. Report it privately
through GitHub:
[report a vulnerability](https://github.com/segla-io/brygga/security/advisories/new).

Include what is affected (the Lodia version and the tenant's Kubernetes
minor), how to reproduce it and the impact you see. We confirm receipt, agree
on a disclosure date with you, and publish the fix with a GitHub security
advisory.
